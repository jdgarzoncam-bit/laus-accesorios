# LAU'S — Sistema de diseño y fundamentos de interfaz

## Dirección visual
Identidad juvenil, editorial, elegante y accesible. La paleta rosa blush/coral es protagonista sin excluir al público masculino. Se combina con blanco cálido, grafito y tonos neutros.

## Tokens base
- Blush: #E9B9C4
- Rose: #D98998
- Coral: #D77D82
- Pale: #F5DFE1
- Ink: #30292D
- Muted: #8E7F83
- Line: #EADFE1
- Canvas: #FBF7F6
- White: #FFFFFF

## Tipografía
- Sora: títulos, precios destacados y titulares editoriales.
- DM Sans: navegación, formularios, datos y texto de lectura.

## Lenguaje de interfaz
- Radios generosos (14–30 px), tarjetas limpias y espacios amplios.
- Botones primarios en grafito con texto blanco; acciones secundarias en blush.
- Estados de sistema discretos: borrador, publicado, agotado, error y éxito.
- Glassmorphism reservado para capas de enfoque (ficha de producto, autenticación, diálogos); no usarlo en cada panel ni sacrificar legibilidad.
- Iconografía Lucide de trazo fino.
- Fotografía de producto como protagonista; no aplicar filtros que alteren el color real de las piezas.

## Comportamiento responsive
- Móvil: navegación compacta, controles táctiles, una columna de tarjetas y formularios apilados.
- Tableta: dos columnas cuando el contenido lo permita.
- Escritorio: navegación lateral/encabezado estable, tablas y paneles de dos o tres columnas.
- Evitar scroll horizontal en catálogo y formularios; tablas administrativas deben ofrecer vista adaptada.

## Fundación visual del Bloque 1
Este bloque define tokens, tipografía, botones, campos, superficies, alertas y estados de carga compartidos. El shell final de LAUS STUDIO se diseñará en el bloque de administración; no se debe anticipar una interfaz de gestión con datos ficticios.
